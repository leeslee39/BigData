### 1-1. 테이블 분석

1.  device_quotas
    `이 테이블은 디바이스의 아이디에 얼만큼의 크레딧이 있고 얼마나 사용했는지 저장하는 테이블이다.`

2.  intros
    `이 테이블은 각각 유저가 적은 한 줄 소개와 이 소개가 얼만큼 노출되고 선택되었는지 나타내는 테이블이다.`

3.  ip_bans
    `이 테이블은 부정사용자를 막기 위해 ip 벤과 벤 사유를 저장하는 테이블이다.`

4.  seen
    `이 테이블은 기존 테이블 기능과 분리해 운영중에 새로운 기능을 추가하기 위해 만든 테이블로, 언제 마지막으로 노출되었는지를 저장한다.`

5.  share_credits
    `이 테이블은 친구 초대로 이 페이지에 들어온 사람들이 각각 누구에게 소개를 받았는지 저장하는 테이블이다.`

6.  share_tockens
    `이 테이블은 토큰들을 관리하는 테이블이다.`

7.  stats_daily
    `이 테이블은 관리자의 운영을 위해 일일 기록을 저장하는 테이블이다.`

8.  stats_device_daily
    `이 테이블은 DAU를 측정하기 위해 활성화 된 디바이스의 로그를 저장하는 테이블이다.`

9.  stats_intro_daily
    `이 테이블은 인트로별 얼마나 노출되었는지 관리하는 파생 데이터이다.`

이 중 가장 가치가 있어보이는 테이블 intros의 행별 의미를 분석해 보겠다.

    <summary>일시별 교차표 쿼리문</summary>
    
    WITH DateCalc AS (
        SELECT 
            shown_count,
            CAST(
                julianday(date(created_at)) - 
                julianday((SELECT date(MIN(created_at)) FROM intros)) 
            AS INTEGER) + 1 AS day_diff
        FROM intros
    )
    SELECT 
        '평균 노출 횟수(shown_count)' AS "구분",
        ROUND(AVG(CASE WHEN day_diff = 1 THEN shown_count END), 2) AS "1일차",
        ROUND(AVG(CASE WHEN day_diff = 2 THEN shown_count END), 2) AS "2일차",
        ROUND(AVG(CASE WHEN day_diff = 3 THEN shown_count END), 2) AS "3일차",
        ROUND(AVG(CASE WHEN day_diff > 3 THEN shown_count END), 2) AS "기타(4일 이상)",
        ROUND(AVG(shown_count), 2) AS "전체 평균"
    FROM DateCalc;

WITH DateCalc AS (
SELECT
shown_count,
gender,
CAST(
julianday(date(created_at)) -
julianday((SELECT date(MIN(created_at)) FROM intros))
AS INTEGER) + 1 AS day_diff
FROM intros
),
DayGroup AS (
SELECT
shown_count,
gender,
CASE
WHEN day_diff = 1 THEN '1. 1일차'
WHEN day_diff = 2 THEN '2. 2일차'
WHEN day_diff = 3 THEN '3. 3일차'
ELSE '4. 기타(4일 이상)'
END AS "일차"
FROM DateCalc
)
SELECT
"일차",
COUNT(CASE WHEN UPPER(gender) = 'M' THEN 1 END) AS "남성 (건수)",
ROUND(AVG(CASE WHEN UPPER(gender) = 'M' THEN shown_count END), 2) AS "남성 (평균 노출)",
COUNT(CASE WHEN UPPER(gender) = 'F' THEN 1 END) AS "여성 (건수)",
ROUND(AVG(CASE WHEN UPPER(gender) = 'F' THEN shown_count END), 2) AS "여성 (평균 노출)"
FROM DayGroup
GROUP BY 1

##### 1. 여성 유저의 경우'

여성 데이터의 가장 큰 특징은 노출 수(분모)가 수백 단위로 남성보다 압도적으로 높다는 점이다. 이 때문에 선택률 자체는 1~3%대로 낮아 보일 수 있지만, 실제 매칭된 절대적인 횟수(평균 선택 수)를 보면 진짜 효율을 파악할 수 있다.

- **최고 효율 구간 (16자):** 여성 데이터 중 가장 높은 전환율을 기록한 구간은 16자(6.01%)였다. 평균 299.5회 노출되어 무려 18회의 선택을 받았다. 군더더기 없이 본인의 핵심 매력만 깔끔하게 전달했을 때 타율이 가장 좋았다.
- **최다 매칭 구간 (23자):** 가장 많은 실제 선택을 이끌어낸 구간은 23자(평균 21.0회 선택)였다. 앞선 분석에서 21~25자 구간이 노출 수가 꺾이는 '애매한 구간'이었으나, 이 길이를 뚫고 살아남아 제대로 매력을 어필한 소수의 유저들은 압도적인 실수요(선택)를 챙겨갔다.

결과적으로 여성 유저는 구구절절 길게 줄글을 쓰기보다는, **15자에서 23자 사이**로 간결하면서도 센스 있게 자신을 표현할 때 가장 많은 매칭 기회를 얻었다는 것을 알 수 있다.

###### 2. 남성 유저의 경우

반면 남성 유저들은 기본 노출 수 자체가 10~70회 수준으로 매우 적었다. 즉, 한 번 노출되었을 때 무조건 선택을 받아내야 하는 고효율 전환이 필수적이었고, 데이터는 남성들에게 두 가지 확실한 성공 공식을 보여주었다.

- **전략 A: 18자**
  남성 데이터에서 가장 경이로운 수치를 보여주는 곳이 바로 18자 구간이다. 평균 136.5회 노출되어 47.25회 선택을 받으며 무려 **34.62%**라는 압도적인 전환율을 기록했다. 노출 수가 1~2건에 불과해 비율만 높게 나온 다른 구간과 달리, 18자는 충분한 노출 대비 전환율이 확실하게 높았다. 너무 짧지도, 지루하게 길지도 않은 딱 18자의 텍스트가 가장 이상적인 균형을 이룬 길이로 보인다.
- **전략 B: 30자 초과**
  서비스 후반부에 30자 제한이 풀린 후, 이를 활용해 길게 작성한 것은 전원 남성 유저였다. 32자(선택률 30.3%), 34자(선택률 11.32%) 데이터를 보면, 정성스럽게 길게 쓴 남성들이 실제로 꽤 높은 노출과 선택을 이끌어냈다는 점이 흥미롭다. 다른 남성들이 짧고 성의 없이 적을 때, 본인의 스펙과 진정성을 꽉 채워 어필한 남성들은 그 정성을 인정받아 높은 확률로 매칭에 성공했다.

##### 3. 무의미한 짧은 글(1~10자)의 비애

남녀를 불문하고 가장 많은 유저가 분포해 있는 곳은 1~10자 구간(남성 170명, 여성 55명)이다. `안녕하세요`, `친해져요` 등 성의 없고 짧은 글이 주를 이루는 이 구간은 노출 대비 선택률이 남녀 모두 적다.

특히 남성의 경우 전체의 절반 가까이가 이 구간에 몰려 있었지만, 돌아오는 평균 선택 수는 고작 1~3회에 그쳤다. 소개팅 서비스에서 귀찮음은 곧 매칭 실패로 직결된다는 것을 데이터가 명확히 증명해 준다.

7.  사용자 입장에서 바로 적용하면 좋은 방식

공통

1. **활성 상태 유지**가 최우선입니다.
2. **초반 진입**이 유리합니다. 런칭/행사/트래픽 몰리는 시점엔 늦게 들어갈수록 손해가 큽니다.
3. 자기소개는 **짧은 1문장 + 구체 정보 1개 + 의도 1개**가 가장 안정적입니다.
4. 인스타는 전원이 적고 있어서, **“인스타 있음” 자체는 차별화가 아닙니다.**

남성 사용자라면

- 제일 큰 문제는 **노출 부족**입니다.
- 그래서 “매력도 극대화”보다 먼저 **노출 받을 수 있는 상태를 오래 유지**해야 합니다.
- 소개문은 **11~20자 정도의 짧고 구체적인 문장**이 좋습니다.
- 잘 먹히는 방향은 대체로
  **따뜻함 / 대화 가능성 / 구체 취미 / 전공·직군 정보 / 관계 의도**입니다.

예시 방향:
“컴공이고 노래방 좋아해요. 편하게 친해져요”
이런 식으로 **정보 + 분위기**를 같이 주는 형식이 유리합니다.

= 여성 사용자라면

- 이미 노출은 충분히 받는 편이라, 중요한 건 **클릭/열람 전환율**입니다.
- 너무 짧은 인사말보다 **11자 이상으로 캐릭터를 드러내는 문장**이 낫습니다.
- 잘 먹히는 방향은
  **분위기 있는 한 줄 / 원하는 상대에 대한 가벼운 필터 / 성격 또는 캐릭터 표현**입니다.

예시 방향:
“천천히 알아갈 사람 찾고 있어요 :)”
처럼 **의도와 톤이 보이는 한 줄**이 좋습니다.

이번 분석은 이렇게 했습니다.

- `is_active`는 설명 변수에서 제외
- 자기소개가 영향을 줄 수 있도록 **실제로 노출된 프로필만** 사용: `shown_count > 0`인 **348개**

- `revealed_count > shown_count` 1건은 비율 왜곡을 막기 위해 `shown_count`로 cap
- 데이터 기간이 짧아서, **가입일 차이(created_at day)** 는 보정해서 봤습니다

결론부터 말하면,
**선택받는 자기소개는 “짧은 인사”보다 “내가 어떤 사람인지 + 어떻게 알아가고 싶은지”가 들어간 문장**이었습니다.
그리고 **취미만 적는 소개는 생각보다 약했습니다.**

핵심 결론

1.  길이는 `11~20자`가 가장 안정적으로 좋았습니다

| 성별 | 1~3자 선택률 | 4~10자 |   11~20자 |    21자+ |
| ---- | -----------: | -----: | --------: | -------: |
| 남성 |         6.0% |   6.5% | **11.3%** |     3.4% |
| 여성 |         2.6% |   2.4% |  **3.3%** | **3.3%** |

가입일을 보정해서 봐도 같은 방향이었습니다.

- **남성**: `11~20자`는 `1~3자` 대비 **1.85배 유리**, `21자+`는 **0.50배로 불리**
- **여성**: `11~20자`는 `1~3자` 대비 **1.33배 유리**, `21자+`도 **1.29배 유리**

즉,

- **남성은 짧지만 정보 있는 1문장**이 가장 좋고
- **여성은 너무 짧지만 않으면**, 11자 이상에서 확실히 좋아졌습니다

2.  어떤 소개 방식이 선택받았는가

제가 자기소개를 아래처럼 나눠서 봤습니다.

- **인사만**: “안녕하세요”, “하이”, “반가워요”
- **자기정보**: 나이, 학과, 성향, 캐릭터, 분위기

2.  선호도 전략: "어떤 사람이 선택(Reveal)받는가?"

단순히 많이 보여지는 것보다 중요한 것은 **'얼마나 매력적인가'**입니다. 이를 위해 **노출 대비 선택 비율(Reveal Rate)**이 높은 그룹을 분석했습니다.

[MBTI별 선호도 순위 (Top 5)]
데이터 상에서 노출 대비 실제 선택으로 이어진 비율이 높은 MBTI 유형입니다.

| 순위    | MBTI     | 평균 선택률 (Reveal Rate) | 특징 및 매력 포인트 (추정)            |
| :------ | :------- | :------------------------ | :------------------------------------ |
| **1위** | **ESTP** | **11.6%**                 | 활동적이고 시원시원한 이미지          |
| **2위** | **ENTP** | **7.5%**                  | 재치 있고 대화가 잘 통할 것 같은 느낌 |
| **3위** | **ENTJ** | **5.8%**                  | 자기주도적이고 스마트한 이미지        |
| **4위** | **ISFJ** | **5.5%**                  | 다정하고 배려심 깊은 이미지           |
| **5위** | **INFJ** | **4.9%**                  | 진중하고 신비로운 분위기              |

- **판단 근거:** **E(외향형)**와 **T(사고형)** 조합이 상위권을 차지했습니다. 사용자들은 대체로 '솔직하고 명확한' 성격을 선호하는 경향이 있습니다. 반면, 데이터상에서 가장 많은 비중을 차지하는 INFP 등은 상대적으로 선택률이 낮게 나타나, **희소성 있는 MBTI**가 더 주목받는 것으로 보입니다.

3.  바이오(Bio) 작성 전략: "한 줄의 마법"

상위 5%의 선택률을 기록한 '인기 유저'들의 자기소개 데이터를 분석한 결과입니다.

[인기 유저의 자기소개 패턴]

1.  **목적의 명확성:** "즐겁게 놀고 싶습니다", "예쁘게 연애하고 싶네요" 등 본인의 니즈를 분명히 밝힘.
2.  **자기 객관화 키워드:** "수줍은 공대생", "옷 좋아합니다", "토끼상" 등 상대방이 나를 상상할 수 있는 키워드 활용.
3.  **친근한 말투:** "안녕하세요", "반가워요" 등 기본적인 인사를 포함한 경우 신뢰도가 상승하여 선택률이 높음 (상관계수 분석 결과, 소개글 길이와 선택률은 약 **0.23**의 양의 상관관계를 보임 → 지나치게 짧은 것보다 **성의 있는 한두 문장**이 유리).

def item_to_db_row(item: Dict[str, Any], region_name: str) -> Dict[str, Tuple]:

    complex_id = str(get_by_keys(item, ["단지기본일련번호", "complex_id"]))
    address = " ".join([
        get_by_keys(item, ["시군구주소", "구주소", "신주소"]),
        get_by_keys(item, ["상세번지내용", "번지", "지번주소"]),
    ]).strip()
    complex_name = get_by_keys(item, ["단지명", "매물명"])

    if not complex_id:
        unique_string = f"{address}_{complex_name}".encode("utf-8")
        complex_id = "CUSTOM_" + hashlib.md5(unique_string).hexdigest()[:12]
        if not complex_name:
            complex_name = f"임의단지({address})"

    bcode = get_by_keys(item, ["법정동코드", "_법정동코드"])

    complex_data = (
        complex_id,
        complex_name,
        region_name,
        bcode,
        address,
        get_number(item, ["연면적내용", "연면적"]),
        normalize_date_text(get_by_keys(item, ["준공년월일", "사용승인일", "사용년"])),
        get_number(item, ["총세대수", "세대수"]),
        get_number(item, ["용적률내용", "용적률"]),
        get_number(item, ["건폐율내용", "건폐율"]),
    )

    # --- 2. REALTOR (중개소) ---
    realtor_name = get_by_keys(item, ["중개업소명"])
    tel = get_by_keys(item, ["중개업소전화번호"])
    realtor_id = hashlib.md5(f"{realtor_name}_{tel}".encode("utf-8")).hexdigest()

    realtor_data = (
        realtor_id, realtor_name, get_by_keys(item, ["중개업소대표자명"]), tel, get_by_keys(item, ["중개업소주소"])
    )

    # --- 3. PROPERTY (매물) ---
    deal_type = get_by_keys(item, ["매물거래구분명", "거래구분"])
    sale_price = get_number(item, ["매매가"])
    deposit_price = get_number(item, ["월세보증금", "전세가"])
    price_value = sale_price if deal_type == "매매" else deposit_price

    property_data = (
        int(get_number(item, ["매물일련번호", "atclNo", "매물기본일련번호"]) or 0),
        complex_id, realtor_id, deal_type, price_value,
        get_number(item, ["월세가", "월세"]),
        get_number(item, ["관리비", "월관리비"]),
        get_by_keys(item, ["융자금", "융자금내용"]),
        get_by_keys(item, ["주택형타입내용", "공급면적"]),
        get_number(item, ["방수"]),
        get_number(item, ["욕실수"]),
        get_number(item, ["전용면적"]),
        get_number(item, ["순전용면적"]),
        get_number(item, ["순공급면적"]),
        get_by_keys(item, ["매물동명", "건물동명", "동", "동명"]),
        get_by_keys(item, ["해당층수", "해당층"]),
        get_number(item, ["건물최고층수", "총층수"]),
        get_by_keys(item, ["현관구조내용", "현관구조"]),
        get_by_keys(item, ["방향구분명", "방향"]),
        get_by_keys(item, ["입주가능일내용", "입주가능일"]),
        get_number(item, ["wgs84위도"]),
        get_number(item, ["wgs84경도"]),
        get_by_keys(item, ["특징광고내용"]),
        get_by_keys(item, ["매물상태구분명"]),
        get_by_keys(item, ["매물등록년월일", "최초등록일시", "등록년월일"]),
        get_by_keys(item, ["매물확인년월일", "확인일자"]),
        build_property_url(item)
    )

    return {
        "complex": complex_data,
        "realtor": realtor_data,
        "property": property_data
    }

def db_writer_worker(db_path: str, db_queue: queue.Queue) -> None:
    conn = sqlite3.connect(db_path, timeout=60)
    try:
        conn.execute("PRAGMA journal_mode=WAL;")

        sql_complex = """
        INSERT OR IGNORE INTO COMPLEX (
            complex_id, complex_name, region_name, bcode, address, total_area,
            usage_approval_date, total_households, floor_area_ratio, building_coverage_ratio
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
        """
        sql_realtor = "INSERT OR IGNORE INTO REALTOR VALUES (?, ?, ?, ?, ?)"
        sql_property = """
        INSERT OR REPLACE INTO PROPERTY (
            property_id, complex_id, realtor_id, deal_type, price, monthly_rent,
            maintenance_fee, loan_info, type_name, room_count, bath_count, private_area, net_private, net_supply,
            dong, floor_info, total_floors, entrance_type, direction, move_in_date, lat, lng,
            ad_feature, status, reg_date, confirmed_at, url
        ) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?, ?)
        """

        complex_batch = set()
        realtor_batch = set()
        property_batch = []
        last_flush = time.time()

        while True:
            try:
                item_list = db_queue.get(timeout=1)
            except queue.Empty:
                item_list = None

            if item_list is DB_SENTINEL:
                if property_batch:
                    conn.executemany(sql_complex, list(complex_batch))
                    conn.executemany(sql_realtor, list(realtor_batch))
                    conn.executemany(sql_property, property_batch)
                    conn.commit()
                db_queue.task_done()
                break

            if item_list is not None:
                for row_dict in item_list:
                    if row_dict["property"][0]:
                        complex_batch.add(row_dict["complex"])
                        realtor_batch.add(row_dict["realtor"])
                        property_batch.append(row_dict["property"])
                db_queue.task_done()

            now = time.time()
            if len(property_batch) >= 500 or (property_batch and now - last_flush >= 2):
                conn.executemany(sql_complex, list(complex_batch))
                conn.executemany(sql_realtor, list(realtor_batch))
                conn.executemany(sql_property, property_batch)
                conn.commit()

                complex_batch.clear()
                realtor_batch.clear()
                property_batch.clear()
                last_flush = now
    finally:
        conn.close()

def fetch_complex_detail(complex_id: str, region_name: str = "COMPLEX") -> Optional[Dict[str, Any]]:
    params = {"단지기본일련번호": complex_id}
    for attempt in range(1, MAX_RETRY + 1):
        try:
            resp = session.get(
                COMPLEX_DETAIL_URL,
                headers=HEADERS,
                params=params,
                timeout=(CONNECT_TIMEOUT, READ_TIMEOUT),
                verify=False,
            )
            if resp.status_code != 200:
                time.sleep(attempt)
                continue
            data = resp.json()
            detail = extract_complex_detail_data(data)
            if detail:
                return detail
            time.sleep(attempt)
        except Exception as e:
            log_debug(region_name, f"complex_id={complex_id} attempt={attempt} complex detail 예외: {repr(e)}")
            time.sleep(attempt)
    return None

def enrich_missing_complexes(db_path: str) -> None:
    conn = sqlite3.connect(db_path, timeout=60)
    updated_count = 0
    failed_count = 0
    try:
        conn.execute("PRAGMA journal_mode=WAL;")
        cur = conn.cursor()
        cur.execute("""
            SELECT DISTINCT c.complex_id
            FROM COMPLEX c
            INNER JOIN PROPERTY p ON p.complex_id = c.complex_id
            WHERE c.complex_id NOT LIKE 'CUSTOM_%'
              AND (
                    c.property_type_name IS NULL OR
                    c.usage_approval_date IS NULL OR
                    c.total_buildings IS NULL OR
                    c.regulation_names IS NULL
                  )
            ORDER BY c.complex_id
        """)
        complex_ids = [str(row[0]) for row in cur.fetchall() if row[0]]
        total = len(complex_ids)
        if total == 0:
            print("추가 단지 보강 대상이 없습니다.")
            return

        print(f"단지 상세 보강 시작: {total}개")
        update_sql = """
        UPDATE COMPLEX SET
            complex_name = COALESCE(NULLIF(?, ''), complex_name),
            bcode = COALESCE(NULLIF(?, ''), bcode),
            address = COALESCE(NULLIF(?, ''), address),
            total_area = COALESCE(?, total_area),
            usage_approval_date = COALESCE(NULLIF(?, ''), usage_approval_date),
            total_households = COALESCE(?, total_households),
            floor_area_ratio = COALESCE(?, floor_area_ratio),
            building_coverage_ratio = COALESCE(?, building_coverage_ratio),
            property_type_name = ?,
            completion_years = ?,
            occupancy_years = ?,
            is_reconstruction = ?,
            is_urban_living_house = ?,
            is_capital_area = ?,
            is_basement = ?,
            total_buildings = ?,
            highest_floor = ?,
            lowest_floor = ?,
            normal_households = ?,
            union_households = ?,
            rental_households = ?,
            building_highest_floor = ?,
            total_parking_count = ?,
            parking_per_household = ?,
            heating_type = ?,
            heating_fuel = ?,
            constructor_name = ?,
            developer_name = ?,
            move_in_month = ?,
            sale_month = ?,
            is_redevelopment = ?,
            is_earthquake_resistant = ?,
            supply_area_text = ?,
            sale_count = ?,
            jeonse_count = ?,
            monthly_rent_count = ?,
            land_area = ?,
            building_area = ?,
            min_supply_area = ?,
            max_supply_area = ?,
            min_contract_area = ?,
            max_contract_area = ?,
            regulation_names = ?,
            complex_updated_at = CURRENT_TIMESTAMP
        WHERE complex_id = ?
        """
        for idx, complex_id in enumerate(complex_ids, start=1):
            detail = fetch_complex_detail(complex_id)
            if not detail:
                failed_count += 1
                print(f"[{idx}/{total}] 단지 {complex_id} 보강 실패")
                continue

            conn.execute(update_sql, build_complex_update_tuple(detail, complex_id))
            updated_count += 1

            if idx % 50 == 0:
                conn.commit()
            print(f"[{idx}/{total}] 단지 {complex_id} 보강 완료")

        conn.commit()
        print(f"단지 상세 보강 완료: 성공 {updated_count}건 / 실패 {failed_count}건")
    finally:
        conn.close()

def select_region_interactive() -> List[Tuple[str, str]]:
    if msvcrt is None:
        print("sel 모드는 Windows 콘솔에서만 지원합니다.")
        return []

    selected = [False] * len(REGION_LIST)
    cursor = 0
    display_limit = 15

    while True:
        clear_screen()
        print("전국 지역 선택 모드 (sel)")
        print("=" * 60)
        print("↑/↓ 이동 | Space 체크/해제 | Enter 시작 | A 전체선택/해제 | Q 취소")
        print("-" * 60)

        start_idx = max(0, cursor - display_limit // 2)
        end_idx = min(len(REGION_LIST), start_idx + display_limit)

        if end_idx - start_idx < display_limit:
            start_idx = max(0, end_idx - display_limit)

        for i in range(start_idx, end_idx):
            region_name, _ = REGION_LIST[i]
            pointer = ">" if i == cursor else " "
            check = "[x]" if selected[i] else "[ ]"
            print(f"{pointer} {check} {region_name}")

        print(f"\n... 전체 {len(REGION_LIST)}개 중 {start_idx+1}~{end_idx} 표시 중 ...")

        key = msvcrt.getch()
        if key in (b"\x00", b"\xe0"):
            key2 = msvcrt.getch()
            if key2 == b"H": cursor = (cursor - 1) % len(REGION_LIST)
            elif key2 == b"P": cursor = (cursor + 1) % len(REGION_LIST)
            continue

        if key == b" ": selected[cursor] = not selected[cursor]
        elif key == b"\r":
            chosen = [REGION_LIST[i] for i, v in enumerate(selected) if v]
            return chosen if chosen else REGION_LIST[:]
        elif key in (b"a", b"A"):
            all_on = all(selected)
            selected = [not all_on] * len(selected)
        elif key in (b"q", b"Q"): return []

def fetch_page(bjd_code: str, page_num: int, region_name: str) -> Optional[Dict[str, Any]]:
    payload = {
        "법정동코드": bjd_code, "페이지번호": page_num, "페이지목록수": 30,
        "거래유형": "1,2,3", "물건종류": "01,05,41", "정렬타입": "priceA",
        "webCheck": "Y", "분양단지구분코드": "C01", "중복타입": "02", "zoomLevel": 12,
    }
    for attempt in range(1, MAX_RETRY + 1):
        try:
            resp = session.post(URL, headers=HEADERS, json=payload, timeout=(CONNECT_TIMEOUT, READ_TIMEOUT), verify=False)
            if resp.status_code != 200:
                time.sleep(attempt); continue
            data = resp.json()
            if '"resultCode": 30500' in json.dumps(data):
                time.sleep(attempt); continue
            return data
        except Exception as e:
            log_debug(region_name, f"page={page_num} attempt={attempt} 예외: {repr(e)}")
            time.sleep(attempt)
    return None

def prescan_first_pages(target_region_list: List[Tuple[str, str]]) -> Dict[str, Dict[str, Any]]:
    global first_page_cache
    first_page_cache = {}
    prescan_lock, prescan_cond, prescan_active = threading.Lock(), threading.Condition(), [0]

    print("전국 지역 전체 페이지 수 확인 중...")
    print(f"프리스캔 쓰레드 수 : {MAX_PRESCAN_WORKERS}")
    print("=" * 100)

    def prescan_worker(region_name: str, bjd_code: str) -> None:
        with prescan_cond:
            while prescan_active[0] >= MAX_PRESCAN_WORKERS: prescan_cond.wait()
            prescan_active[0] += 1
        try:
            set_status(region_name, "전체페이지 확인중")
            data = fetch_page(bjd_code, 1, region_name)
            if not data:
                mark_failed(region_name)
                return
            total_pages = max(1, get_total_pages(data))
            with prescan_lock: first_page_cache[region_name] = data
            update_total_pages(region_name, total_pages)
            set_status(region_name, f"프리스캔 완료 ({total_pages}p)")
        finally:
            with prescan_cond:
                prescan_active[0] -= 1
                prescan_cond.notify()

    threads = []
    for region_name, bjd_code in target_region_list:
        t = threading.Thread(target=prescan_worker, args=(region_name, bjd_code), daemon=True)
        t.start(); threads.append(t); time.sleep(0.01)

    for t in threads: t.join()
    return first_page_cache

def build_page_queue(target_region_list: List[Tuple[str, str]]) -> queue.Queue:
    q: queue.Queue = queue.Queue()
    scheduled = sorted(target_region_list, key=lambda x: progress_info[x[0]]["total_pages"], reverse=True)
    for region_name, bjd_code in scheduled:
        for page_num in range(1, progress_info[region_name]["total_pages"] + 1):
            q.put((region_name, bjd_code, page_num))
    return q

def page_worker(page_queue: queue.Queue, db_queue: queue.Queue) -> None:
    global active_workers
    with active_workers_lock: active_workers += 1
    try:
        while True:
            try: region_name, bjd_code, page_num = page_queue.get_nowait()
            except queue.Empty: break

            try:
                set_status(region_name, f"수집중 {len(completed_pages[region_name]) + 1}/{progress_info[region_name]['total_pages']}")
                data = first_page_cache.get(region_name) if page_num == 1 else fetch_page(bjd_code, page_num, region_name)

                if data:
                    prop_array = find_property_array(data)
                    if prop_array:
                        rows = [item_to_db_row(item, region_name) for item in prop_array if isinstance(item, dict)]
                        if rows:
                            db_queue.put(rows)
                            add_property_count(region_name, len(rows))
                update_page_done(region_name, page_num)
            except Exception as e:
                log_debug(region_name, f"page={page_num} worker 예외: {repr(e)}")
                update_page_done(region_name, page_num)
            finally:
                page_queue.task_done()
    finally:
        with active_workers_lock: active_workers -= 1

def progress_monitor(target_region_list: List[Tuple[str, str]]) -> None:
    global monitor_running
    display_limit = 20

    while monitor_running:
        with progress_lock: snapshot = {k: dict(v) for k, v in progress_info.items()}
        with stats_lock:
            total_properties = stats["total_properties"]
            processed_pages = stats["processed_pages"]
            total_pages = stats["total_pages"]
            start_time = stats["start_time"]

        elapsed = max(1.0, time.time() - start_time)
        eta = max(0, total_pages - processed_pages) * ((elapsed / processed_pages) if processed_pages > 0 else 0)

        clear_screen()
        print("전국 부동산 수집 진행 현황 (DB 정규화 버전)")
        print("=" * 150)

        all_done = True
        active_count = 0
        for region_name, _ in target_region_list:
            info = snapshot[region_name]
            if not info["done"]: all_done = False

            if not info["done"] and active_count < display_limit:
                bar = render_bar(info["current_page"], info["total_pages"])
                percent = (info["current_page"] * 100.0 / info["total_pages"]) if info["total_pages"] > 0 else 0.0
                status_str = "실패" if info["failed"] else "완료" if info["done"] else info["status"]
                print(f"{region_name[:12]:<12} {bar} {info['current_page']:>4}/{info['total_pages']:<4} {percent:>6.1f}%  매물:{info['property_count']:<7} 상태:{status_str}")
                active_count += 1

        if len(target_region_list) > display_limit:
            print(f"... (외 {len(target_region_list) - active_count}개 지역 처리 중) ...")

        print("-" * 150)
        print(f"전체 진행률        : {(processed_pages * 100.0 / total_pages) if total_pages > 0 else 0.0:.1f}% ({processed_pages} / {total_pages} pages)")
        print(f"실시간 수집 카운트 : {total_properties} 건")
        print(f"초당 매물 수       : {total_properties / elapsed:.2f} 건/s")
        print(f"예상 남은 시간 ETA : {format_eta(eta)}")
        print(f"작업중 쓰레드 수   : {active_workers} / {MAX_WORKERS}")
        print("=" * 150)

        if all_done: break
        time.sleep(1.5)

def print_db_summary(db_path: str = DB_PATH) -> None:
    if not os.path.isfile(db_path):

        return
    conn = sqlite3.connect(db_path)
    try:

        print("\n===== DB 요약 =====")

    finally:
        conn.close()

def main() -> None:
    global monitor_running
    ensure_dir(OUT_DIR); ensure_dir(LOG_DIR)

    parser = argparse.ArgumentParser()
    parser.add_argument("mode", nargs="?", default="crawl", choices=["crawl", "sel", "summary"])
    parser.add_argument("--db-path", default=DB_PATH)
    args = parser.parse_args()

    if args.mode == "summary":
        print_db_summary(args.db_path)
        return

    target_region_list = select_region_interactive() if args.mode == "sel" else REGION_LIST[:]
    if not target_region_list: return

    # [매우 중요!] DB가 바뀌었으므로 기존 파일이 있으면 삭제
    if os.path.exists(args.db_path):
        print(f"기존 DB 파일 '{args.db_path}'을(를) 삭제하고 새로 생성합니다.")
        os.remove(args.db_path)

    init_sqlite_db(args.db_path)

    for region_name, _ in target_region_list:
        progress_info[region_name] = {"total_pages": 0, "current_page": 0, "done": False, "failed": False, "property_count": 0, "status": "대기중"}
        completed_pages[region_name] = set()

    prescan_first_pages(target_region_list)
    page_queue = build_page_queue(target_region_list)
    db_queue: queue.Queue = queue.Queue(maxsize=200)

    monitor_running = True
    monitor_thread = threading.Thread(target=progress_monitor, args=(target_region_list,), daemon=True)
    monitor_thread.start()

    writer_thread = threading.Thread(target=db_writer_worker, args=(args.db_path, db_queue), daemon=True)
    writer_thread.start()

    workers = [threading.Thread(target=page_worker, args=(page_queue, db_queue), daemon=True) for _ in range(MAX_WORKERS)]
    for w in workers: w.start(); time.sleep(0.02)
    for w in workers: w.join()

    db_queue.put(DB_SENTINEL); db_queue.join(); writer_thread.join()

    with progress_lock:
        for region_name, _ in target_region_list:
            if progress_info[region_name]["current_page"] >= progress_info[region_name]["total_pages"]:
                progress_info[region_name]["done"] = True
                if progress_info[region_name]["status"] != "실패": progress_info[region_name]["status"] = "완료"

    monitor_running = False
    monitor_thread.join(timeout=2)

    print("\n매물 수집 완료. 단지 상세 보강을 시작합니다.")
    enrich_missing_complexes(args.db_path)

    print(f"\n수집 완료: {args.db_path}")

from playwright.sync_api import sync_playwright
import pandas as pd

import re
import time

URL = "https://kbland.kr/r/4117310400?xy=37.3779077,126.9574378,14&brif=region&brifId=4117310400"

def clean_text(s: str) -> str:
    if not s:
        return ""
    return re.sub(r"\s+", " ", s).strip()

def safe_inner_text(locator):
    try:
        return clean_text(locator.inner_text(timeout=1000))
    except:
        return ""

def safe_get_attr(locator, name):
    try:
        return locator.get_attribute(name, timeout=1000) or ""
    except:
        return ""

def collect_cards(page):
    data = []

    # 사이트 구조가 바뀔 수 있어서 후보 셀렉터를 넓게 둠
    card_selectors = [
        "a[href*='/se/l/p/']",
        "a[href*='/l/p/']",
        "[data-testid*='card']",
        "article",
        "li"
    ]

    cards = None
    for sel in card_selectors:
        loc = page.locator(sel)
        if loc.count() > 10:
            cards = loc
            print(f"[INFO] Using selector: {sel}, count={loc.count()}")
            break

    if cards is None:
        print("[WARN] 카드 셀렉터를 확정하지 못함. 전체 링크 기반으로 시도.")
        cards = page.locator("a")

    count = cards.count()
    print(f"[INFO] total candidate elements = {count}")

    seen = set()

    for i in range(count):
        card = cards.nth(i)

        try:
            text = clean_text(card.inner_text(timeout=1000))
        except:
            text = ""

        href = safe_get_attr(card, "href")
        if href and href.startswith("/"):
            href = "https://kbland.kr" + href

        # KB부동산 상세 매물 링크 위주로 필터
        if "/l/p/" not in href and "/se/l/p/" not in href:
            if len(text) < 15:
                continue

        key = href or text
        if not key or key in seen:
            continue
        seen.add(key)

        lines = [clean_text(x) for x in text.split("\n") if clean_text(x)]

        record = {
            "url": href,
            "raw_text": text,
            "line_1": lines[0] if len(lines) > 0 else "",
            "line_2": lines[1] if len(lines) > 1 else "",
            "line_3": lines[2] if len(lines) > 2 else "",
            "line_4": lines[3] if len(lines) > 3 else "",
        }

        # 가격/면적/층수 같은 패턴 대충 잡기
        m_price = re.search(r"(매매|전세|월세)\s*([^\s]+.*)", text)
        if m_price:
            record["deal_type"] = m_price.group(1)
            record["price_guess"] = clean_text(m_price.group(2))
        else:
            record["deal_type"] = ""
            record["price_guess"] = ""

        m_area = re.search(r"(\d+(?:\.\d+)?)\s*㎡", text)
        record["area_m2_guess"] = m_area.group(1) if m_area else ""

        m_floor = re.search(r"(\d+/?\d+층|\d+층)", text)
        record["floor_guess"] = m_floor.group(1) if m_floor else ""

        data.append(record)

    return data

def auto_scroll(page, rounds=10, pause=1.5):
    last_height = 0
    for r in range(rounds):
        page.mouse.wheel(0, 4000)
        time.sleep(pause)

        try:
            height = page.evaluate("document.body.scrollHeight")
        except:
            height = 0

        print(f"[INFO] scroll round {r+1}/{rounds}, height={height}")
        if height == last_height:
            # 리스트 영역이 따로 있을 수 있어서 오른쪽 목록 패널도 스크롤 시도
            try:
                page.locator("body").press("End")
                time.sleep(1)
            except:
                pass
        last_height = height

def main():
    with sync_playwright() as p:
        browser = p.chromium.launch(headless=False)

            user_agent=(

                "AppleWebKit/537.36 (KHTML, like Gecko) "
                "Chrome/124.0.0.0 Safari/537.36"
            ),
            locale="ko-KR"
        )
        page = context.new_page()

        print("[INFO] open page")
        page.goto(URL, wait_until="domcontentloaded", timeout=90000)
        page.wait_for_timeout(5000)

        # 팝업/가이드 닫기 시도
        possible_buttons = ["닫기", "오늘 그만 보기", "확인", "동의", "허용 안 함"]
        for txt in possible_buttons:
            try:
                btn = page.get_by_text(txt, exact=False)
                if btn.count() > 0:
                    btn.first.click(timeout=1000)
                    page.wait_for_timeout(1000)
            except:
                pass

        auto_scroll(page, rounds=12, pause=2.0)
        rows = collect_cards(page)

        # 중복 제거
        dedup = []
        seen = set()
        for r in rows:
            k = (r.get("url", ""), r.get("raw_text", ""))
            if k in seen:
                continue
            seen.add(k)
            dedup.append(r)

        print(f"[INFO] collected rows = {len(dedup)}")

        df = pd.DataFrame(dedup)
        df.to_csv("kbland_region_4117310400.csv", index=False, encoding="utf-8-sig")
        with open("kbland_region_4117310400.json", "w", encoding="utf-8") as f:
            json.dump(dedup, f, ensure_ascii=False, indent=2)

        print("[DONE] saved:")
        print(" - kbland_region_4117310400.csv")
        print(" - kbland_region_4117310400.json")

        # 디버깅용 HTML 저장
        with open("kbland_region_page.html", "w", encoding="utf-8") as f:
            f.write(page.content())
        print(" - kbland_region_page.html")

        browser.close()

if __name__ == "__main__":
    main()
